## 🌟 Overview
**NEXUS** is an interactive, web-based analytics dashboard designed to explore restaurant market patterns, customer demand, cuisine clusters, and quality metrics at a glance. Built entirely in Python using Streamlit, this tool acts as a "Market Intelligence Core" for analyzing real-world restaurant data.

## ✨ Key Features
- **🎛️ Data Explorer & Filter Matrix**: Dynamically filter the dataset by city, cuisine, cost, user ratings, and vote count.
- **🧠 AI-Style Market Insights**: Immediate summaries for top-rated, most-voted, and highest-value options.
- **📊 Interactive Visualizations**: Features scatter plots for cost-vs-rating value mapping, and bar charts for geographic density and top cuisines.
- **🌃 Dark Mode UI**: A fully customized, futuristic aesthetic built with custom CSS.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY_NAME.git
cd YOUR_REPOSITORY_NAME
```

### 2. Install dependencies
Make sure you have Python installed, then run:
```bash
pip install -r requirements.txt
```

### 3. Run the dashboard
```bash
streamlit run app.py
```
*The app will automatically open in your default web browser.*

## 📁 Repository Structure
- `app.py`: The main Streamlit dashboard application logic and UI.
- `restaurants.csv`: The dataset containing restaurant locations, ratings, and metrics.
- `requirements.txt`: List of required Python packages to run the project.
